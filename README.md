#  Edna Moda App

Aplicación de escritorio desarrollada en Java para la gestión de citas de un taller de diseño de trajes.

## Funcionalidades
- Gestión de clientes
- Gestión de trajes
- Gestión de talleres
- Gestión de citas

## Tecnologías
Java · MySQL · JDBC · Eclipse · GitHub

Documentación completa en la Wiki del repositorio.
